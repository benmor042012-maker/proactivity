# Proactivity

> חדש כאן? תתחילי מ-**`START-HERE.md`** — הוא מסביר הכל בעברית פשוטה.

האתר כולו הוא קובץ אחד — `index.html`. פותחים אותו בדפדפן וזהו, אין התקנה
ואין שרת.

## להריץ מקומית

לחיצה כפולה על `index.html` עובדת לרוב הדברים. חלק מהיכולות (Service Worker,
התקנה כאפליקציה, וטופס התשלום) דורשות כתובת אמיתית ולא `file://`, ולשם כך:

    python3 -m http.server 8000

ואז לפתוח <http://localhost:8000>.

## לערוך

**אין לערוך את `index.html` ישירות** — הוא נוצר אוטומטית ויידרס. עורכים את
המודולים שב-`tools/` ומריצים:

    python3 tools/build.py

הסקריפט גם בודק את עצמו: מפתח תרגום כפול, שפה חסרה, `{placeholder}` שלא תואם
בין חמש השפות, או קבוצת גיל עם חור בשאלות — כל אחד מאלה עוצר את הבנייה.

`tools/README.md` מפרט מה יש בכל קובץ.

## מבנה

| | |
|---|---|
| `START-HERE.md` | מדריך פתיחה — איך לתת את הפרויקט ל-Claude ולהמשיך לעבוד |
| `index.html` | האתר המלא — נוצר, לא נערך |
| `tools/` | המקור: טבלאות התרגום, ה-CSS, ה-HTML וה-JS |
| `sw.js`, `manifest.webmanifest` | עבודה אופליין והתקנה כאפליקציה — נוצרים גם הם |
| `PAYMENTS.md` | איך מדליקים תשלום בכרטיס אשראי, צעד אחר צעד |
| `icon-*.png`, `og.png` | אייקונים ותמונת שיתוף |

## תשלום

כרגע האתר במצב פתוח: שום דבר לא נעול, ולא נטען שום סקריפט תשלום.
`PAYMENTS.md` מסביר מה צריך כדי להדליק את זה — וגם מה אי אפשר לעקוף.
